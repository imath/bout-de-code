# Bout de code

## Requirements:

- [Retraceur](https://retraceur.github.io/) >= 3.2.0
- PHP >= 7.4


## Description

![screenshot](https://github.com/user-attachments/assets/7ea4d474-902b-4dc8-97de-9ff3d72b4d8e)

"Bout de code" (which means Code Snippet) is a Retraceur block letting you embed code snippets hosted on [Gist.GitHub.com](https://gist.github.com) into your posts or pages.
